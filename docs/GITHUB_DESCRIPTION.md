# StudyApp

StudyApp is a Hebrew-first **desktop-only** learning app (Python + customtkinter). There is no browser version and no web server.

**Current public release: 4.5.3**

- Windows 10 / Windows 11: run `StudyApp-4.5.3-setup.exe`, or unzip and run `StudyApp.exe`
- Linux (Ubuntu, Debian, Fedora, Arch, openSUSE, Alpine, …): `./StudyApp.sh` from the portable tarball
- In-app updates from Settings; optional anonymous version ping (off by default)
