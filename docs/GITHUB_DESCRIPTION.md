# StudyApp

StudyApp is a Hebrew-first **desktop-only** learning app (Python + customtkinter). There is no browser version and no web server.

**Current public release: 5.0.1**

- Windows: prefer `StudyApp-5.0.1-setup.exe`, or unzip `StudyApp-5.0.1-windows.zip` and run `StudyApp.exe`
- If GitHub download fails (school network): use the raw mirror  
  https://raw.githubusercontent.com/or2005/StudyApp/downloads/StudyApp-5.0.1-setup.exe
- Linux: `./StudyApp.sh` from the portable tarball
- In-app updates from Settings; «הורדה בדפדפן» if the built-in download stalls
