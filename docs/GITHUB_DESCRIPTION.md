# StudyApp

StudyApp is a Hebrew-first **desktop-only** learning app (Python + customtkinter). There is no browser version and no web server.

**Current public release: 5.0.2**

- Windows: prefer `StudyApp-5.0.2-setup.exe`, or unzip `StudyApp-5.0.2-windows.zip` and run `StudyApp.exe`
- If GitHub download fails (school network):  
  https://raw.githubusercontent.com/or2005/StudyApp/downloads/StudyApp-5.0.2-setup.exe
- Linux: `./StudyApp.sh` from the portable tarball
- In-app updates from Settings; «הורדה בדפדפן» if the built-in download stalls
- Local AI via Ollama (optional): check connection in Settings; pull model e.g. `ollama pull qwen2.5:3b`
