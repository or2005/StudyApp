# StudyApp, Release Notes 4.5.0

## Overview
StudyApp is a Hebrew-first **desktop** study app. It runs on **Windows 10**, **Windows 11**, and **Linux** (no browser).

## Downloads
- Windows 10/11: `StudyApp-4.5.0-setup.exe` or `StudyApp-4.5.0-windows.zip` → `StudyApp.exe`
- Linux (all common distros): `StudyApp-4.5.0-linux-portable.tar.gz` → `./StudyApp.sh`

## What's new
- Fresh teal app icon
- In-app toasts, updated home screen, and tighter practice feedback
- Automatic in-app update check still keeps learning progress

## Notes
Educational support tool. Not an official Bagrut or Meimad exam.
